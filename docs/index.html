Popout-billederne er tegnet med skinnenes farver som eksempel. Tallene er illustrationer, ikke målinger.

Installation

Tre trin. Ingen build, ingen kode.

  1. 1
    Hent skinnet fra GitHub: hjemplus.tmogskin eller hjemplus-nat.tmogskin.
  2. 2
    Åbn skins-mappen i TMOG: View ▸ Popout Skin ▸ Open Skins Folder — eller Settings ▸ Interface ▸ Skins Folder. Læg filen dér.
  3. 3
    Reload Skins og vælg Hjem+ eller Hjem+ Nat i listen.
